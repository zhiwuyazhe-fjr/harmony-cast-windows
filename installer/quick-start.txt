鸿蒙手机连接助手

USB 有线连接

1. 用支持数据传输的 USB 线连接鸿蒙手机与 Windows 电脑。
2. 在手机开发者选项中开启 USB 调试，解锁后允许这台电脑连接。
3. 从开始菜单打开「鸿蒙手机连接助手」。启动时只发现一台已授权的 USB 手机会自动投屏。
4. 稍后插线或同时连接多台设备时，点击「刷新设备」，选中手机并点击「开始投屏」。

Wi-Fi 无线连接

手机和电脑需要在同一局域网并能互相访问。在手机上开启无线调试，在助手的「Wi-Fi 无线」中填写手机显示的 IPv4 地址和端口。
也可以接入一台已授权的 USB 手机，刷新设备后点击「通过 USB 获取无线地址」，由助手打开手机的 5555 调试端口并填入地址。
点击「连接并投屏」，允许手机上的调试授权。看到无线画面后即可拔下 USB 线。

预览操作

F11    切换全屏
Esc    退出全屏
C      显示或隐藏连接面板

底栏可以调整画面大小和背景。停止投屏后可以调整画质。声音由手机播放。
如需排查连接问题，点击「打开日志目录」查看 mirror.log。
