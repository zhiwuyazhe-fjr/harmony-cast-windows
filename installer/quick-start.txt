肌智 JixFit 演示投屏 1.0.0

安装完成后，从桌面或开始菜单打开“肌智 JixFit 投屏”。

首次连接手机

1. 使用支持数据传输的 USB 线连接鸿蒙手机与电脑。
2. 在手机开发者选项中开启 USB 调试。
3. 在手机弹出的调试授权提示中允许这台电脑连接。
4. 只有一台已授权的 USB 手机时，应用会自动开始投屏。
5. 若尚未出现画面，按 C 展开控制台，点击“刷新设备”和“开始投屏”。

展示快捷键

F11    全屏展示
Esc    退出全屏
C      显示或隐藏控制台

底部可调整画面大小和背景。停止投屏后可调整画质并重新连接。

此安装包已包含 Python、Qt、Java、HDC 和视频解码运行库。
手机使用 Windows 自带的 WinUSB 驱动。更换电脑后需在手机上重新授权。

已验证的手机为华为畅享 90 Plus，HarmonyOS 7.0.0.111。
无线入口可在控制台中找到，当前版本优先使用 USB 有线投屏。

故障日志可以从控制台里的“日志”按钮打开。
